# LS810V 演示程序 · 素材总览

坐标系：屏幕 480 × 640，原点左上角，单位 = 设备像素。

| 目录 | 内容 | 嵌入式是否需要 |
|---|---|---|
| `01_screen_ui/` | 屏幕 UI 素材 | **需要** |
| `02_demo_content/` | 演示用示例图 | 不需要 |
| `03_lut/` | 滤镜 3D LUT | 按需 |
| `04_font/` | 子集字体 + 文案清单 | **需要** |
| `音效文件/` | 操作音效 wav（演示页不播放，仅随素材包提供） | 按需 |

每个子目录下都有一份 `README.md`，说明该目录里每个素材的：尺寸、出现的页面、屏幕坐标、注意事项。
