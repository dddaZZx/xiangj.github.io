# 音效文件 —— 操作音

| 文件 | 时长 | 触发时机 |
|---|---|---|
| `click.wav` | 0.05 s | 任意设备按键按下（OK / 方向键 / SET / FLASH / SHUTTER / 电源） |
| `shutter.wav` | 0.43 s | 拍照成功瞬间 |
| `poweron.wav` | 1.08 s | 开盖开机完成、进入取景界面时 |
| `poweroff.wav` | 1.08 s | 长按电源键关机时 |
| `wrong.wav` | 0.21 s | 操作无效：未插卡拍照 / 卡满 / 格式异常 / 无法进相册 |

格式：单声道 WAV，16000 Hz，16 bit。

注意：

- 演示页里已内嵌这 5 个 wav（data URI），**不需要外部文件也能播放**
- 浏览器限制：页面加载后的第一次播放必须由用户操作触发；开机音因为随自动开盖播放，部分浏览器首次会被静音拦掉，点一下任意按钮后即可正常
- 右侧工具栏有「音效：开 / 关」按钮，可整体关闭
- 固件若要做音效，需要 PWM/DAC 输出 + 相同采样率的音频数据，采样率与时长可直接复用
