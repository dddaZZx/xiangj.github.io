# 01_screen_ui —— 屏幕 UI 素材

固件真正需要的素材都在这里。子目录按用途划分：

| 子目录 | 内容 |
|---|---|
| `battery/` | 右上角电量图标（bat0~4 + charging） |
| `flash/` | 左上角闪光灯状态图标（自动 / 开 / 关） |
| `charging/` | 关机充电的全屏 5 帧动画 |
| `icons/` | USB、SD 警示、颗粒贴图 |
| `settings/` | 设置类界面的底图、行底图、箭头 |
| `ui/` | 提示框、变焦胶囊的九宫格底图 |
| `boot.png` | 开机 LOGO（480×640） |
| `shutdown.png` | 关机画面（480×640） |

通用约定：

- 全部为 RGBA PNG，直接贴到 framebuffer，不需缩放
- 带「9 宫格」字样的素材：四角不拉伸，四边单向拉伸，中心填充
- 半透明素材叠在实时取景上，注意芯片是否有 alpha 混合
