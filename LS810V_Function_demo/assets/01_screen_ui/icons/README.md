# icons/ —— 通用图标

| 文件 | 尺寸 | 页面 | 坐标 (x, y) | 说明 |
|---|---|---|---|---|
| `usb.png` | 309×189 | USB 模式 | 165, 274 | 缩放到 150×92 居中显示 |
| `sdwarn.png` | 40×40 | 拍照（未插卡） | 12, 588 | 红色存储卡 + 感叹号：无卡 |
| `sd_full.png` | 40×40 | 拍照（卡满） | 12, 588 | 红色存储卡，**无符号**：存储卡已满 |
| `sd_bad.png` | 40×40 | 拍照（格式异常） | 12, 588 | 红色存储卡 + **X**：存储卡格式不符合要求 |
| `grain.png` | 96×96 | 拍照 / 全屏浏览 | 平铺 | 颗粒噪点，按档位改透明度 |

注意：

- 三个 SD 卡图标**位置、尺寸完全一致**，只是中间符号不同，切换时直接换图
- 左下角，左 12、下 12：`y = 640 - 40 - 12 = 588`
- 出现规则（拍照界面才显示，离开拍照界面隐藏）：
  - 未插卡 → `sdwarn.png`
  - 卡格式异常 → `sd_bad.png`（优先级高于卡满）
  - 存储卡已满 → `sd_full.png`
  - 正常 → 不显示
- `usb.png` 原图 309×189，显示时等比缩放到宽 150（高约 92），水平居中 `(480-150)/2 = 165`，垂直居中 `(640-92)/2 = 274`
- `grain.png` 是平铺贴图，透明度档位 0 / 0.07 / 0.14 / 0.24
