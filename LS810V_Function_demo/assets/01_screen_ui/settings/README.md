# settings/ —— 设置类界面

适用于「主设置」「拍照设置」两种列表界面。

| 文件 | 尺寸 | 页面 | 坐标 (x, y) | 说明 |
|---|---|---|---|---|
| `settings_bg.png` | 480×640 | 主设置 / 拍照设置 | 0, 0 | 全屏底图：顶栏 + 分割线 + 列表底色 |
| `row_normal.png` | 32×32 | 同上 | 每行 (0, y) | **9 宫格**，切片 8：透明底 + 底部 2px 线 |
| `row_selected.png` | 32×32 | 同上 | 每行 (0, y) | **9 宫格**，切片 8：选中行底色 `#dfe6e9` |
| `row_disabled.png` | 32×32 | 同上 | 每行 (0, y) | **9 宫格**：禁用行，线 32% 透明 |
| `ic_arrow.png` | 24×24 | 同上 | 438, y+29 | 子菜单箭头（未选中，`#8e9ba2`） |
| `ic_arrow_dark.png` | 24×24 | 同上 | 438, y+29 | 子菜单箭头（选中行，`#4a565e`） |

版式参数：

| 项 | 值 |
|---|---|
| 顶栏 | y 0–44，底色已含在 `settings_bg.png` |
| 顶栏标题 | 左边距 16，字号 18，字距 2px，颜色 `#8e9ba2`，垂直居中 y=22 |
| 页码 | 顶栏右侧，右边距 16，格式 `1/2` |
| 列表起点 | y = 46 |
| 行高 | 84（含底部 2px 线，所以行底图拉伸到 480×84） |
| 行内左边距 | 18（左文本） |
| 行内右边距 | 18（右值右对齐到 x=462） |
| 左文本 | 字号 22，`#dfe6e9`；选中行 `#12171a` |
| 右值 | 字号 20，`#8e9ba2`；选中行 `#4a565e` |
| 箭头位置 | x = 438（右边距 18 + 24 宽），垂直居中于行 |
| 禁用行 | 整体 alpha 0.32 |
| 每页行数 | 7（46 + 7×84 = 634 ≤ 640） |

注意：

- 行底图必须按 **9 宫格**拉伸到 480×84，不能整张缩放，否则底部 2px 线会被拉粗
- 选中行与未选中行只换底图，文字颜色由代码决定
- 翻页时整页重绘，不做滚动
