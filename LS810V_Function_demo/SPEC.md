# LS810V 演示 UI — 设计基准 / 资源说明

> **设计基准 = 设备真实分辨率 = 480 × 640**
> 网页里 CSS 写的每一个像素值，就是设备上的一个像素，**不需要任何换算**。

| | 数值 |
|---|---|
| 面板 | 2.4" TFT，物理 640 × 480，竖装 → **480 × 640** |
| 演示 / 设计基准 | **480 × 640** |
| 换算 | **1 : 1** |
| 网页显示 | `zoom` 自动缩到 ≤0.5 倍（只影响观看，不影响数值） |

若固件 framebuffer 实际是 640×480 横置（DSP 旋转输出），
本文所有绝对坐标需先做 90° 旋转映射，**请先确认**。

## 3. 电池图标规格

- 64 × 32，PNG RGBA，**透明背景**
- 背景：alpha = 0（全透明）
- 图形：纯白 `#FFFFFF`，无抗锯齿过渡像素
- 几何（相对 64×32 画布）：
  - 电池外框 `(3,4)-(52,28)`，圆角 R4，描边 3px
  - 正极头 `(54,12)-(59,20)`
  - 电量格 4 个：x = 9 / 19 / 29 / 39，每格 7 × 14（y 9–23），圆角 R1
  - 充电态为白色闪电多边形，居中
- 屏幕贴图位置：距屏幕上边 **12**、右边 **12**
- 仅在拍照（预览）界面显示

> 素材自带透明通道，网页里直接叠在画面上，不需要任何混合模式。

## 3.2 滤镜

4 档，拍照界面用 **◀ ▶** 循环切换，默认第 1 档：

| # | 中文名 | 英文名 | LUT 文件 |
|---|---|---|---|
| 1 | 标准 | Normal | 无（原图） |
| 2 | 暖调复古 | Warm Vintage | `lut/warm.cube` |
| 3 | 冷调清透 | Cool Tone | `lut/cool.cube` |
| 4 | 黑白 | B&W | `lut/bw.cube` |

- LUT 格式：`.cube`，`LUT_3D_SIZE 17`，`DOMAIN 0..1`，顺序 R 变化最快、B 最慢（标准 .cube 约定）
- 每条 LUT 与网页内嵌数据同源（网页为离线运行，把 17³ 数据以 base64 内嵌，避免 file:// 下取不到文件）
- 切换时：黑条自左→右（按 ▶）/ 自右→左（按 ◀）扫过 420ms，扫到一半时换图
- 画面中央浮出滤镜名称小框，**停留 1.5s** 后淡出；中文界面显示中文名，英文界面显示英文名
- 音量一致：滤镜只改颜色，不做缩放/裁切

### 3.3 数码变焦

- 拍照界面 **▲ ▼** 调节，默认 **X1**，范围 **X1 ~ X8**
- 短按：整档 ±1（X1→X2→X3…，到顶/到底钳位）
- 长按：按住 **380ms** 后进入连续调节，速度 **3.0 倍/秒**，松手停在当前值（可为小数，如 X6.4）
- 显示：画面**顶部居中**的胶囊标签，统一一位小数（`X1.0` / `X4.0` / `X6.4`），与无极调节对应
- 该标签**平时不显示**，只在调节时淡入，停手后 **1.5s** 淡出
- 顶部三个元素（闪光灯图标 / 变焦标签 / 电量图标）的**垂直中心线对齐**在距屏幕上边 32px
- 画面以中心为原点做数字缩放，`transform: scale()`，不改变画幅比例

## 3.4 相册缩略图加载

- 进入相册时**不一次性显示全部缩略图**，先整屏铺骨架（底色 #1b2124，中间灰色 ...，无动画）
- 按行从视口顶部开始，每 **70ms** 点亮一张，直到当前可见行全部显示
- 下翻（选择框移出可视区触发布局滚动）后，新进入视口的行按同样规则继续加载
- 已经点亮过的缩略图在同一次相册浏览中不再重复加载；退出相册再进入则从头加载
- 骨架与缩略图共用 137×137、圆角、选中描边，切换时不改变布局

## 3.5 截屏（演示程序工具，非设备功能）

- 画面左侧「关盖」按钮上方有 **截屏** 按钮，仅演示程序使用，固件不实现
- **canvas 内容的处理**：<canvas> 画出来的像素不会随 HTML 序列化带走，序列化前先对每个 canvas 调用 	oDataURL()，把结果作为同尺寸 ackground-image 贴回克隆节点，这样设置界面 / 提示框等 canvas 绘制的部分也能正确截到
- 点击瞬间同步克隆屏幕节点，冻结当前状态后转成 480×640 PNG 下载
- 相册缩略图正在逐个加载时点击，截到的是当帧的骨架状态（已加载的显示图片，未加载的显示 ...）
- 文件名格式：LS810V_YYYYMMDD_HHMMSS.png

| 栏位 | 按钮 | 行为 |

## 3.8 关机充电画面

- 触发条件：已连接充电线 **且** 电源状态为关机（off）
- 整屏黑底，中央一个 172×91 的电池：白色圆角外框（线宽 16）+ 右侧电极 + 内部 4 格
- 动画：点亮格数 **0 → 1 → 2 → 3 → 4 → 0** 循环，一格 0.5s，整周期 2.5s（opacity 阶梯切换，无渐变）
- 与右上角电量图标同一造型语言：四格电池，只是放大到全屏
- **接着充电线关机时不显示 GoodBye 关机画面**，直接进入本画面
- 拔掉充电线即回到黑屏关机状态；开盖或长按电源键可正常开机

## 3.9 TF 卡缺失状态

- 状态与左侧工具栏「拔出 / 插入 TF 卡」一致，拔卡后：
  1. **拍照界面左下角**显示红色 SD 卡标志（40×40，距左 12、距下 12）
  2. 按 SHUTTER **不拍照**，画面中央弹出提示框「未插入存储卡 / No card inserted」，1.6s 后消失
  3. **设置 → 存储** 的值显示「未插入 / No card」
  4. **设置 → 相册** 与 **设置 → 格式化** 两行都置灰（透明度 0.32），上下移动时**自动跳过**，按 OK 无响应
  5. 若在相册界面时拔卡，自动退回拍照界面
- 插回 TF 卡后以上提示立即消失，格式化恢复可选

## 3.10 操作指引（演示程序工具）

右侧工具栏「操作指引」开关，**目前只做拍照界面**，标注 4 个实体按键（SET / FLASH / ON-OFF / SHUTTER）

实现要点：

- 覆盖层用 SVG **按屏幕坐标绘制**（position:fixed 全屏，z-index 30），不挂在机身内部，避免被机身 3D 图层遮挡

样式规范：

- 文本框 **100 × 26**、圆角 6，字号 10；两行文本时框高自动增至 40
- 底色 
gba(18,22,27,.72)、描边 
gba(255,255,255,.20)、文字 
gba(255,255,255,.95)
- **文本框 X 固定在机身外侧**：左列右边、右列左边统一距离机身边缘 16，不随机身内按键位置变化，也不与机身重叠
- **文本框与对应按键严格垂直居中**（纵向跟随按键）
- 方向键没有独立元素外框（四个键是重叠的 154×154 盒子），用 pad 中心 ± 偏移定位，连线终点落在箭头图形右侧 26px
- 连线：**一条纯水平虚线**（1.6px，
gba(43,108,201,.95)，8 6 间隔）
  - 左列：起点 = 文本框**右边中点**，终点 = 按键**左边中点**

## 3.14 按键图标与字体依赖

- 机身按键图标**全部是内联 SVG**（SET 三横线 / FLASH 闪电 / ON-OFF 电源符号 / SHUTTER 圆环），
  不下载图片、不依赖系统字体里的 Unicode 字形，任何机器打开渲染一致
- 方向键 ▲▼◀▶ 仍用 Unicode 字符（U+25B2/25BC/25C0/25B6，各系统均自带，风险极低）
- 素材包内附 **`素材说明.md`**：逐个素材列出名称、尺寸、出现页面、屏幕坐标、注意事项

## 3.17 提示框：九宫格素材 + 子集字体

所有提示框已从「纯 CSS 画」改为「**九宫格素材 + 文本**」，字体用内嵌的 **子集 TTF**。

| 元素 | 实现 |
|---|---|
| 中央提示（未插入存储卡 / 已保存 等） | `toast_bg.png` 九宫格，字号 22 |
| 滤镜名称浮窗 | 同一张 `toast_bg.png`，字号 28 |
| 变焦 `X1` | `hud_bg.png` **横向 3 段**，高 40 |
| 字体 | `@font-face` 内嵌 `LS810V_ui.ttf`（微软雅黑子集，429 汉字，103 KB）|

**绘制方式：canvas，不是 CSS `border-image`。**

机身整体用 `zoom < 1` 缩放显示，`border-image` 的边框宽度会变成小数（如 14.36px），
浏览器切片渲染在切片边界会留下约 1px 的细缝，肉眼能看到竖线。

改为：每个提示框内部放一个 `<canvas class="bg">`，按**整数设备像素**把九宫格画进 canvas
（4 角贴图 + 4 边单向拉伸 + 中心填充），再由浏览器整体缩放一次。这样只有一次均匀重采样，不会出现接缝。

文字同样画在 canvas 上：用 measureText 的 ctualBoundingBoxAscent/Descent 取**墨迹上下边界**，
按 y = (h - (asc+desc)) / 2 + asc 放置基线，保证任何字号下视觉都垂直居中
（之前用 DOM 文字 + flex 居中，居中用的是行盒而不是字形，字号一大就偏下，字号一小就偏上）。

框尺寸由文字测量结果决定：`w = ceil(文字宽 + 2×左右内边距)`，`h = 固定高或 行高 + 2×上下内边距`；
文字用 DOM `<span>` 叠在 canvas 上，字体即子集 TTF。

素材：

| 文件 | 尺寸 | 说明 |
|---|---|---|
| `01_screen_ui/ui/toast_bg.png` | 64×64 | 圆角 10，切片 16，`rgba(0,0,0,.62)` |
| `01_screen_ui/ui/hud_bg.png` | 96×40 | 圆角 20，左右切片 20，`rgba(0,0,0,.55)` |
| `04_font/LS810V_ui.ttf` | 103 KB | 含界面全部中文字符，去 hinting |

为什么变焦 HUD 不能用 9 宫格：高度只有 40，上下圆角各 20 已占满高度，中间没有可拉伸区，
只能横向 3 段（左右半圆固定、中间拉宽）。

嵌入式实现提示：

- 大提示框：4 角贴图 + 4 边单向拉伸 + 中心填色，宽度随文字测量结果变化
- 变焦框：固定高 40，左右各贴 20px 端点图，中间横向拉伸
- 字体：FreeType 加载 `LS810V_ui.ttf`，字号 22 / 28 两档；字距（letter-spacing）1px / 3px 需自行实现或忽略
- 半透明叠在取景画面上，若芯片无 alpha 混合能力，可把底图改成不透明

## 3.21 首屏加载与开盖

首次打开（尤其是公网访问、网络较慢时）不再闪现巨大机身，而是：

1. `<head>` 末尾先执行一段内联脚本，按窗口高度把机身 `zoom` 设好 —— 首帧就是正确比例
2. 初始状态为**关盖 + 黑屏**，机身中央显示「加载中…」提示
3. `window.load`（所有内嵌图片解码完）后，提示淡出，自动播放**开盖动画**（上盖翻起 + 开机 LOGO）进入取景界面
4. 提示至少显示 0.6 秒，避免一闪而过；另设 6 秒兜底，即使有图加载失败也一定进入界面

机身设计高度 1480，缩放公式：`k = min(0.5, (innerHeight - 32) / (1480 + 96))`。

## 3.22 存储卡状态：正常 / 卡满 / 格式异常

左侧工具栏「拔出存储卡」下面是三个**互斥**的状态按钮，当前生效的那个显示蓝色底（`.panel button.on`）：

| 按钮 | 含义 | 按下后 |
|---|---|---|
| `正常` | 卡正常 | 清除卡满 / 格式异常 |
| `卡满` | 卡已满 | 卡自动视为已插入；清除格式异常 |
| `格式异常` | 卡格式不符 | 卡自动视为已插入；清除卡满；若在相册则退回拍照 |

三个按钮的文案固定不变，靠蓝色底表示当前状态——不像开关按钮那样"点一下换个词"。

### 与「拔出存储卡」的关系

四种状态互斥，任意时刻只有一种：**未插卡 / 正常 / 卡满 / 格式异常**。

- 按「拔出存储卡」→ 未插卡，卡满 / 格式异常清零，按钮变「插入存储卡」
- 按三个状态按钮任意一个 → 卡视为已插入（按钮变「拔出存储卡」）
- 未插卡时三个状态按钮都不高亮

### 左下角图标

| 状态 | 图标 | 说明 |
|---|---|---|
| 未插卡 | `sdwarn.png` | 红卡 + 感叹号 |
| 格式异常 | `sd_bad.png` | 红卡 + X |
| 卡满 | `sd_full.png` | 纯红卡，无符号 |
| 正常 | 不显示 | — |

只出现在拍照界面，离开拍照界面自动隐藏；三个图标 40×40、坐标固定 (12, 588)。

### 行为差异

| 操作 | 卡满 | 格式异常 |
|---|---|---|
| 按快门 | 提示「存储卡已满」，不拍 | 提示「卡格式不符合要求，请重新格式化」，不拍 |
| 长按 OK / 相册项 | **可以**进相册 | **不允许**：只提示，不弹确认框 |
| 格式化 | 可以（完成后**恢复正常**） | 可以（完成后**恢复正常**） |

- **拍照界面长按 OK（550ms）直接进入相册**（看刚拍的照片）；短按 OK 进拍照设置

- 列表超出一屏时自动滚动，保证选中行始终可见
- **执行格式化**：整屏黑底 + 中央旋转指示环（64×64，6px 白环，0.9s/圈）+「格式化中...」文字，持续 **2 秒**

  - 结束后照片清空、存储显示 0.0 MB，返回设置界面
- 拍照界面点击画面可循环切换电池图标，仅供工程师看效果
