# ui/ —— 提示框底图

| 文件 | 尺寸 | 页面 | 坐标 (x, y) | 说明 |
|---|---|---|---|---|
| `toast_bg.png` | 64×64 | 全部界面 | 居中 (240, 320) | **9 宫格**，切片 16；圆角 10，`rgba(0,0,0,.62)` |
| `hud_bg.png` | 96×40 | 拍照（变焦） | 水平居中 240, 12 | **横向 3 段**，左右各 20；圆角 20，高 40 |

用法：

- `toast_bg.png`：用于「未插入存储卡」「已保存」等提示，以及「滤镜名称」浮窗。
  宽度 = 文字宽 + 左右各 26；高度 = 字号×1.2 + 上下各 14（滤镜浮窗为 12）。
- `hud_bg.png`：用于变焦倍数 `X1.0`。高度固定 40，左右各 20 不拉伸，中间横向拉宽；
  宽度 = 文字宽 + 左右各 16。

注意：

- `hud_bg.png` 的圆角半径 20，正好等于高度的一半，所以**上下不能拉伸**，只能横向三段
- 两张图都是半透明黑，叠在实时取景上；若芯片无 alpha 混合能力，可换成不透明黑
- 文字用 `LS810V_ui.ttf` 绘制，垂直居中按字形墨迹计算，不要按行高居中
